# 배기 플랩 연구용 파일 수집 v0.2.1 (전체 수집 프로필)

**플랩 제어 기능이 없습니다. 시스템 파일을 USB에 복사하는 분석 도구입니다.**

대상: 한국형 CN7NPE KOR V039.001.260902, TCC803x, NEMESIS 1.16.7 이상 정상 실행 중.

1. ZIP 안의 파일 전체를 USB 최상위에 풉니다. `NEMESIS.data`와 `progress.sh`가 USB 루트에 있어야 합니다. 기존 `NEMESIS.data`는 PC에 먼저 보관하세요.
2. 주차 상태에서 내비가 부팅된 뒤 USB를 데이터 포트에 꽂습니다.
3. NEMESIS가 스크립트를 실행할지 물으면 예를 누릅니다. 화면에 퍼센트·현재 단계·파일 이름·복사/없음 개수가 나옵니다. 진행률은 작업 단계 기준이며 남은 시간을 뜻하지 않습니다.
4. 100%가 나온 다음 NEMESIS 완료 알림까지 확인하고 USB를 분리합니다. 파일 처리 중에는 퍼센트가 그대로일 수 있습니다.
5. USB의 새 결과 폴더에서 `result.txt`를 확인합니다. `collection=COMPLETE`는 파일 추출 완료를 뜻하며 플랩 제어 성공이 아닙니다. `report.txt`는 복사 목록입니다.
6. PC에서 결과 폴더를 ZIP으로 압축해 개발 대화에 비공개로 첨부해 주세요. 제조사 파일이 있으므로 공개 GitHub 이슈·저장소·릴리스에는 올리지 마세요.

파일 복사는 파일당 60초, 앱 목록·경로 확인은 30초, 저장 마무리는 60초 제한입니다. 실패하면 어느 단계에서 멈췄는지 표시하며 100%를 표시하지 않습니다. 커널 수준 USB 입출력 정지는 종료를 지연시킬 수 있습니다. 마지막 상태는 `progress.txt`, 단계별 기록은 `events.log`에 남습니다. `없음`에는 선택 파일도 포함되므로 숫자 자체가 실패를 뜻하지는 않습니다. 실제 차량의 화면 동작은 아직 검증하지 않았습니다.

오류가 나도 결과 폴더가 생겼다면 삭제하지 말고 보관하세요. 다른 펌웨어·다른 플랫폼이면 추출 전에 거부합니다. 결과 폴더는 기존 것을 덮어쓰지 않으며 20개가 있으면 PC로 옮긴 뒤 다시 실행하세요.

설치 앱·부팅 서비스가 없으므로 내비에서 제거할 것은 없습니다. 작업 후 USB의 도구·결과 파일을 지우면 됩니다. 이 USB에는 `NEMESIS.emergency`를 추가하지 마세요.
