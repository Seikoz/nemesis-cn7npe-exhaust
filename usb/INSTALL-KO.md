# 배기 플랩 연구용 파일 수집 v0.1.0

**플랩 제어 기능이 없습니다. 시스템 파일을 USB에 복사하는 분석 도구입니다.**

대상: 한국형 CN7NPE KOR V039.001.260902, TCC803x, NEMESIS 정상 실행 중.

1. ZIP의 네 파일과 LICENSE를 USB 최상위에 풉니다. `NEMESIS.data`가 USB 루트에 있어야 합니다. 기존 `NEMESIS.data`는 PC에 먼저 보관하세요.
2. 주차 상태에서 내비가 부팅된 뒤 USB를 데이터 포트에 꽂습니다.
3. NEMESIS가 스크립트를 실행할지 물으면 예를 누릅니다. 완료까지 USB를 빼지 마세요.
4. USB의 `CN7NPE-exhaust-private-1/report.txt`를 확인합니다. `COMPLETE`는 파일 추출 완료를 뜻하며 플랩 제어 성공이 아닙니다.
5. PC에서 결과 폴더를 ZIP으로 압축해 개발 대화에 비공개로 첨부해 주세요. 제조사 파일이 있으므로 공개 GitHub 이슈·저장소·릴리스에는 올리지 마세요.

오류가 나도 결과 폴더가 생겼다면 삭제하지 말고 보관하세요. 다른 펌웨어·다른 플랫폼이면 추출 전에 거부합니다. 결과 폴더는 기존 것을 덮어쓰지 않으며 20개가 있으면 PC로 옮긴 뒤 다시 실행하세요.

설치 앱·부팅 서비스가 없으므로 내비에서 제거할 것은 없습니다. 작업 후 USB의 도구·결과 파일을 지우면 됩니다. 이 USB에는 `NEMESIS.emergency`를 추가하지 마세요.
